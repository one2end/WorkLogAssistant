# 小红书发布文案

## 主推版本

**标题**
我做了一个免费的软件，专门记住我上班时在电脑上摸鱼还是干活

**正文**

每天下班回顾，都会出现一个诡异的现象：
明明感觉忙了一整天，却说不出自己干了啥 🤯

后来我干脆自己写了个工具，让它替我记得。

它叫 WorkLog，Windows 装完就丢在后台，不占地方。

—

📌 **它到底记什么**

不是记键盘、不截屏、不看内容。
只记一件事：**这个窗口在你前面待了多久**。

比如：
`09:12–09:47  35 分钟  WPS［文档写作］三季度分析报告.docx`
`09:47–10:15  28 分钟  企业微信［沟通协作］邮e联`

最戳我的一点：**你走开它会认出来**。
连续三分钟没碰键鼠，自动标成"离座"，不算进有效工时。
所以那个数字是真实的，不是"电脑开着就算我在工作"。

—

📌 **到点让 AI 写日志**

可以设时间段，比如 12:00 / 18:00 / 22:00。
到点它把这一段的记录丢给 AI，自动生成一份工作日志。

我用的是我自己的 DeepSeek key，一天几分钱。

—

📌 **最爽的功能：AI 能自己来查**

这个可能只有折腾党会喜欢 😂

它内置了一个 MCP 接口，接到 WorkBuddy 或者 Claude 之后，可以直接问：

> 我这周时间花在哪了？和上周比呢
> 上午写方案的时候我都在哪些窗口之间切来切去

它会自己调数据、自己算。不用导表格，不用做透视表。

—

📌 **顺手还做了个专注助手**

番茄钟（25/5）、沉浸（15/15）、罗汉（不计时，只做当下这一件事）。
桌面顶部一个小条，告诉你现在该专注还是该滚去休息。
休息的时候整条会变绿，还挺有仪式感的 🟢

—

📌 **几个我比较在意的点**

✅ 完全本地，数据存在你自己电脑上，不上传
✅ 开源，代码全在 GitHub
✅ 不需要注册账号
✅ 免费，没有内购也没有广告

—

做这个东西最初是为了解决我自己的问题：
**过去要可查，未来才好优化。**

用了两个月，最直观的变化是——
再也不会出现"这天我到底干了啥"的空白了。

—

电脑开着不等于你在工作，这个免费工具能分清楚

**正文**

自己写的一个小软件，装在 Windows 上，后台默默记你每个窗口停留了多久。

三个我喜欢的点：

1️⃣ 走开会自动识别。三分钟没碰鼠标键盘就标"离座"，不计入工时，所以统计出来的时长是准的

2️⃣ 到点让 AI 自动写工作日志，不用下班了靠回忆补

3️⃣ 数据全在本地，还能通过 MCP 让 AI 直接查"我这周时间花在哪了"

免费、开源、不用注册。
